# xkcd colors

The color names people use, from the [xkcd color survey](https://blog.xkcd.com/2010/05/03/color-survey-results/)
(`https://xkcd.com/color/rgb.txt`), public domain under [CC0](https://creativecommons.org/publicdomain/zero/1.0/).

Filtered for the Studio's color names: crude and pejorative names, pop-culture ones, and slash names (`blue/green`) are
dropped; run-together names are spaced (`lightblue` → `light blue`); `grey` is spelled `gray`; the duplicates that made
are dropped. 878 of the 949 names remain.
