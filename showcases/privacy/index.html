Privacy

Last updated November 11, 2026

What this covers

Every Bitview service run at these two addresses:

  • bitview.space: the website and its apps, the REST API and its OpenAPI description, llms.txt and llms-full.txt, and the Agent Skill, which calls the API.
  • mcp.bitview.space: the MCP server, which the Claude Code plugin uses together with the skill.

Bitview is open source, and anyone can run it. A server someone else runs is theirs, under their own policy.

Nothing about you is asked for

There are no accounts, API keys, cookies, analytics, ads or trackers. A request carries only what it asks for, in its path and query: series ids, ranges, block hashes, transaction ids or addresses.

Request logs

The bitview.space server logs one line per request: the time, the method, the status, the path with its query, and how long the answer took. It logs no IP address, no user agent and no other detail about who sent the request.

The lines are kept in daily files on the server, which deletes files older than seven days when it starts. The last 1,000 lines are also public, on the Logs page and at /api/server/logs, so anything in a path or query, an address for example, can be seen there.

The MCP server

At its default log level, the MCP server logs its start (the address it listens on and its tool count) and no tool call. Each tool call becomes a GET request to the bitview.space API, which logs it like any other request, as above. It keeps no sessions, and no record of what was asked or answered.

Network providers

Both addresses are served through Cloudflare, which handles every connection and so sees the IP address it comes from, under Cloudflare's privacy policy.

In your browser

Some apps keep settings and recent choices in your browser's storage, such as Studio's charts or when you last opened each app. They stay on your device and are never sent.

Two pages load files from elsewhere: the Benchmarks page reads its results from GitHub, and the MCP server's pages load their fonts from jsDelivr. Those services receive the request as for any page they serve.

Sharing

Nothing is sold or shared. Beyond the logs above, nothing is kept to share.

Changes and contact

This page changes when the services do, and its date says when it last did. Its history is in the source. Questions: support@bitview.space. The terms for using Bitview are on the terms page.
