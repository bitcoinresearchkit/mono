Connect

Use the root URL as a remote Streamable HTTP MCP server. The same path serves this page to people over GET and the MCP protocol to clients over POST.

  1. Add a remote MCP server Open your client's MCP or connector settings.
  2. Enter the endpoint Use https://mcp.bitview.space/.
  3. Choose no authentication No account, API key, or secret is required.

Client requirement: MCP 2026-07-28 with modern stateless request metadata. Legacy handshakes are not supported.

What it knows

The tool catalog is generated from Bitcoin Research Kit's non-deprecated REST GET operations, so MCP and API capabilities stay aligned.

  • Blockchain

    Blocks, transactions, addresses, outputs, scripts, and UTXOs.

  • Mempool

    Unconfirmed transactions, projected blocks, replacements, and fees.

  • Market

    Current and historical Bitcoin prices across supported currencies.

  • On-chain analytics

    Supply, cohorts, realized metrics, profitability, and distributions.

  • Mining & network

    Hashrate, difficulty, rewards, fee rates, pools, and network state.

  • Discovery

    Search, list, and metadata operations for finding valid identifiers.

Try asking

Start with a question. The client can inspect the catalog and choose the relevant Bitview tools.

  • Summarize the latest Bitcoin block and compare its fees with the previous ten blocks.
  • What fee rate is projected to clear in each of the next three blocks?
  • Compare the current short-term-holder and long-term-holder realized prices.
  • Show Bitcoin's daily closing price and realized capitalization since January 1.

Read-only by design

Bitview MCP reads changing public Bitcoin and market data. It does not expose the REST transaction-broadcast operation and cannot move bitcoin or act on a user's behalf.

  • No private keys
  • No transaction signing
  • No wallet control
  • No trading or transfers
  • No transaction broadcasting
