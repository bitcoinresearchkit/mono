02 / Data

From blocks to market structure.

Each tool asks Bitview's public API one question, across the areas below. Search tools find any metric from plain words.

  • Blockchain

    Blocks, transactions, addresses, scripts, outputs, and UTXOs.

  • Mempool

    Unconfirmed transactions, projected blocks, replacements, and fees.

  • Price

    The BTC/USD price, estimated from the chain's own transactions, with exchange history before 2015.

  • On-chain

    Supply, holder cohorts, realized metrics, profitability, and distributions.

  • Mining

    Hashrate, difficulty, rewards, fee rates, pools, and network state.

  • Discovery

    Search, list, and describe series, so the assistant uses ids that exist.

03 / Ask

Start with a question.

  • What happened in block 840,000, and how much did the miner earn in fees?
  • What fee rate do I need to get into the next block right now?
  • How has Bitcoin's realized price compared with its market price since 2020?
  • Compare the short-term and long-term holders' realized prices today.

04 / Current

Know how current the data is.

  • Confirmed data

    Blocks and every series built on them update as soon as Bitview has processed each new block.

  • Mempool

    Read from Bitcoin Core about once a second, with the projected next block.

  • Status

    Health shows uptime and the heights served, sync status the distance from the node's tip. There is no service-level commitment.

  • Stability

    Series are renamed only in releases, each rename listed in the changelog.

Read-only by design.

{{DISPLAY_NAME}} MCP reads public Bitcoin data. It has no private keys and cannot sign or broadcast transactions, control wallets, or trade or move bitcoin. Each tool call becomes one GET request to the Bitview API; the privacy policy says what is logged.

05 / Build

Open infrastructure.

Bitview is a free, MIT-licensed Bitcoin data server: on-chain metrics, blocks, mempool and mining data, with charts and an API. Use it at bitview.space or run it beside your own Bitcoin Core node. This MCP server lives in the same repository and runs against any Bitview.
